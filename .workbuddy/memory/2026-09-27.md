### 坑 1：`gh` 不在沙箱 shell 的 PATH 里
`gh` 装在 `/opt/homebrew/bin/gh`（brew），但沙箱 PATH 只有 WorkBuddy 的 shim 目录 + `/usr/bin` 等，**没有 `/opt/homebrew/bin`**，所以 `gh` 报 `command not found`（用户终端能用是因为自己的 zsh 配置）。
→ 解决：命令前 `export PATH="/opt/homebrew/bin:$PATH"`。

### 坑 2：`gh api` 的 URL 查询串被 zsh 当 glob
`gh api repos/.../git/trees/main?recursive=1` 里的 `?` 在 zsh 下触发 `no matches found`，命令直接失败。**第一次做泄漏检查时因此走了 `||` 分支，打出假"✓"**——差点把"命令没跑成"当成"检查通过"。
→ 解决：URL 必须加引号。教训：`A && echo ok || echo fail` 这种结构里，A 因语法错误失败也会走 `fail` 分支，不能当验证通过。
